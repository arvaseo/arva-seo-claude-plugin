# Arva SEO plugin

The Arva SEO connector (`https://api.arvaseo.com/mcp`) and three skills: write-content-brief, write-content-draft and improve-page-copy. Claude writes with your Arva SEO websites' details and writing rules, and saves its work to Arva SEO for your review.

Install in Claude Code (2.1.275 or later):

```
/plugin install arva-seo --marketplace arvaseo/arva-seo-claude-plugin
```

After installing, connect Arva SEO from the plugin's Connectors tab (Claude app) or `/mcp` (Claude Code), sign in and approve. See the [marketplace README](../../README.md) for install steps, and [the help article](https://support.arvaseo.com/articles/use-arva-seo-in-claude-or-chatgpt) for details.
